# Referência: filtros e coloração no Dalux

Descrição dos vídeos de referência, passada pelo usuário em 2026-11-13. A equipe não tem acesso aos vídeos; este texto é a fonte.

## Barra inferior do visualizador
- Da esquerda para a direita: **"Filtro ▾"**, **"Medida"**, **"Ampliar tudo"**, **"Editar cores"**, **"Colorir ▾"**.
- À direita: **"Remover filtros"** / **"Remover coloração"**. Só aparecem quando há filtro ou coloração ativos.

## Popover "Filtro"
- Seção **"Filtros salvos"**: uma lista nomeada. Exemplos:
  - EQUIPE 01, EQUIPE 02, EQUIPE 03, EQUIPE 04
  - PADRÃO-Peças expedidas
  - PADRÃO-Peças expedidas no mês
  - PADRÃO-Peças não fabricadas
  - PADRÃO-Quadrante de montagem
- Seção **"Filtro"**:
  - busca **"Pesquisar por objetos"**;
  - menus rápidos: **Arquivo**, **Categoria**;
  - os filtros ativos como **etiquetas removíveis** (ex.: "PEÇA-Data Expedição Plan 2022… ×");
  - **"+ Adicionar filtro"**, **"Avançado"** e **"Salvar ▾"**.

## "+ Adicionar filtro"
Abre **"Selecionar parâmetro"**: uma lista pesquisável de todos os parâmetros do modelo.

## "Avançado" → "Editar filtro"
- Linhas de regra: `[ação: Isolar ▾] [parâmetro] [operador: É igual a ▾] [valor] [editar] [×]`.
- Sempre há uma linha vazia nova ao final.
- Botões **Cancelar** e **Aplicar**.

## Popover "Colorir"
- Busca em todos os parâmetros.
- Escolher um parâmetro pinta **cada valor distinto com uma cor**.
- Caixa **"Cor por gama"**, para faixas contínuas.

## "Editar cores" → janela "Cores"
- Tabela de regras: **cor + nome de um filtro salvo** (ex.: EQUIPE 01 laranja, EQUIPE 02 verde).
- Botões: **Adicionar**, **Editar**, **Remover**, **Mover para cima**, **Mover para baixo**, **Cancelar**, **Salvar**.
- **A ordem define a prioridade.**

## Clique numa peça
- Aparece uma mini barra com **Ocultar**, **Isolar** e **Corte**.
- Atalhos: **H** oculta; **Espaço** amplia no objeto.
